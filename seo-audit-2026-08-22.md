# SEO Audit Report — hmimi.design

**Date:** 2026-08-22 16:58
**Site:** Personal portfolio — Hmimi Chioukh, Product Designer
**Tech:** Next.js 16 (App Router) + Express/MongoDB backend

---

## Executive Summary

**Health: Moderate** — Strong foundation after Next.js migration, but critical gaps remain.

**Top 5 Issues:**
1. Blog pages are 100% client-rendered — invisible to crawlers
2. Homepage has no metadata export
3. Zero structured data (JSON-LD) across entire site
4. No canonical tags on any page
5. Sitemap hardcodes blog slugs that may not match API data

---

## Technical SEO Findings

| # | Issue | Impact | Evidence | Fix | Priority |
|---|-------|--------|----------|-----|----------|
| 1 | **Blog pages are `'use client'` only** — no `generateMetadata` | HIGH | `app/blog/[slug]/page.tsx:1` | Add server component wrapper with metadata generation, or convert to RSC | 1 |
| 2 | **Homepage has no metadata** — `app/page.tsx` is client-only | HIGH | `app/page.tsx:1` | Create `app/layout.tsx` metadata or add `generateMetadata` in a server wrapper | 1 |
| 3 | **No canonical tags anywhere** | HIGH | No `<link rel="canonical">` found | Add `metadataBase` + canonical in layout or per-page metadata | 1 |
| 4 | **No structured data (JSON-LD)** | HIGH | No `application/ld+json` scripts | Add Person schema on homepage, Article on blog, PortfolioCollection | 1 |
| 5 | **Sitemap blog slugs are hardcoded** | MEDIUM | `app/sitemap.ts:7-12` | Should fetch from API or be generated dynamically | 2 |
| 6 | **OG images use relative paths** | MEDIUM | `app/layout.tsx:31` `/og-image.png` | Must be absolute URL (`https://hmimi.design/og-image.png`) | 2 |
| 7 | **No security headers** (HSTS, X-Frame-Options) | LOW | `next.config.ts` | Add `headers()` in next.config.ts | 3 |
| 8 | **Google Fonts loaded via CSS @import** | LOW | `app/globals.css:1-2` | Next.js `next/font` is used in layout — remove duplicate @import | 3 |
